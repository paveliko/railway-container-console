# `changes/`

One folder per proposed change. A change whose work is finished moves to
`archive/`, where the folder name gains the date prefix.

Children of a change prefix their criteria and tasks with a two-letter code:
`V-PR-N` / `T-PR-N` for `probe`, `RT` for `something-else`.
